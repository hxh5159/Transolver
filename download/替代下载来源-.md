## 1. ShapeNet-Car：优先推荐 Paddle 直链

这是最适合你当前 ShapeNet-Car/StageNO 工作的来源。PaddleScience 也在其 [Transolver 文档](https://paddlescience-docs.readthedocs.io/zh-cn/latest/en/examples/transolver/) 和 [PaddleCFD 示例](https://github.com/PaddlePaddle/PaddleCFD/blob/develop/examples/aerodynamic_car_design/README.md)中使用这条下载地址。

```bash
mkdir -p ~/datasets/shapenetcar
cd ~/datasets/shapenetcar

wget -c \
  https://paddle-org.bj.bcebos.com/paddlecfd/datasets/pptransformer/mlcfd_data.zip \
  -O mlcfd_data.zip

unzip mlcfd_data.zip
```

压缩包约 9.56 GB，建议至少预留 25–30 GB。已核对其中包含：

```text
mlcfd_data/
├── training_data/
│   ├── param0/
│   ├── ...
│   └── param8/
└── preprocessed_data/
    ├── param0/
    ├── ...
    └── param8/
```

每个原始样本有：

```text
quadpress_smpl.vtk
hexvelo_smpl.vtk
```

每个预处理样本有：

```text
x.npy
y.npy
pos.npy
surf.npy
edge_index.npy
```

Transolver 参数设置为：

```bash
--data_dir ~/datasets/shapenetcar/mlcfd_data/training_data \
--save_dir ~/datasets/shapenetcar/mlcfd_data/preprocessed_data \
--preprocessed 1
```

可以检查是否完整：

```bash
find ~/datasets/shapenetcar/mlcfd_data/training_data \
  -name 'quadpress_smpl.vtk' | wc -l

find ~/datasets/shapenetcar/mlcfd_data/preprocessed_data \
  -name 'x.npy' | wc -l
```

两项都应输出 `889`。

如果该直链仍不稳定，使用 OneScience：

```bash
python -m pip install -U modelscope

modelscope download \
  --dataset OneScience/ShapeNetCar \
  --local_dir ~/datasets/ShapeNetCar
```

对应路径是：

```text
~/datasets/ShapeNetCar/data/mlcfd_data/training_data
~/datasets/ShapeNetCar/data/mlcfd_data/preprocessed_data
```

## 2. 六个标准 PDE benchmark

国内网络建议先用 ModelScope：

```bash
modelscope download \
  --dataset OneScience/cfd_benchmark \
  --local_dir ~/datasets/cfd_benchmark
```

也可以走 Hugging Face：

```bash
python -m pip install -U huggingface_hub hf_xet

hf download OneScience-Group/cfd_benchmark \
  --repo-type dataset \
  --local-dir ~/datasets/cfd_benchmark
```

下载后运行完整校验：

```bash
cd ~/datasets/cfd_benchmark
python scripts/validate_dataset.py
```

各任务参数对应如下：

| 任务 | `--data_path` |
|---|---|
| Elasticity | `~/datasets/cfd_benchmark/data` |
| Plasticity | `~/datasets/cfd_benchmark/data/plas/plas_N987_T20.mat` |
| 标准 Airfoil | `~/datasets/cfd_benchmark/data/airfoil` |
| Pipe | `~/datasets/cfd_benchmark/data/pipe` |
| Darcy | `~/datasets/cfd_benchmark/data/darcy` |
| Navier–Stokes | `~/datasets/cfd_benchmark/data/ns` |

Navier–Stokes 有一个仓库路径小问题：`exp_ns.py` 额外硬编码了一层同名目录。将其改成仓库中已经写好但被注释的直接路径即可：

```python
data_path = args.data_path + '/NavierStokes_V1e-5_N1200_T20.mat'
```

该镜像附有[文件名、大小及 SHA-256 清单](https://huggingface.co/datasets/OneScience-Group/cfd_benchmark/blob/main/metadata/file_manifest.csv)，与 Transolver 需要的 14 个文件一致。

## 3. AirfRANS

推荐：

```bash
modelscope download \
  --dataset OneScience/airfrans \
  --local_dir ~/datasets/AirfRANS
```

或：

```bash
hf download OneScience-Group/airfrans \
  --repo-type dataset \
  --local-dir ~/datasets/AirfRANS
```

Transolver 参数应指向：

```bash
--my_path ~/datasets/AirfRANS/data/Dataset
```

这个目录中应有：

```text
Dataset/
├── manifest.json
└── <case>/
    ├── <case>_internal.vtu
    ├── <case>_aerofoil.vtp
    └── <case>_freestream.vtp
```

OneScience 数据卡确认其包含 1,000 个原始算例、约 15 GB，并保持 `full/scarce/reynolds/aoa` 划分。[来源说明与目录结构](https://huggingface.co/datasets/OneScience-Group/airfrans)

需要避免：

- [Zenodo ShapeNet-Car](https://zenodo.org/records/13993629)只有表面压力，没有体积速度，不能复现 Transolver 完整汽车任务。
- 普通 ShapeNet/ShapeNetCore 只是 CAD 或点云数据，没有 CFD 场。
- PDEBench、CFDBench 中同名的 Darcy/NS 数据分布和文件格式不同，不能替代 Transolver 的标准 benchmark。
- ShapeNet-Car 原始数据的再分发许可并不清晰，Transolver 作者也曾说明无法自行重新托管；科研复现可以使用这些整理源，但不要直接再次公开分发或商用。[相关说明](https://github.com/thuml/Transolver/issues/5#issuecomment-2521918738)
